# 🧾 ESC/POS Preview

영수증 프린터 없이 ESC/POS 명령어가 어떻게 찍히는지 브라우저에서 바로 확인할 수 있는 도구입니다.

👉 **Live Demo: https://rlnrlnworld.github.io/receipt-preview/**

## 배경

| 시기 | 내용 |
|---|---|
| **2025.07** | 서비스에 들어갈 영수증 출력 모듈을 만들기 전에 ESC/POS 명령어 체계를 익히려고 만든 프로토타입입니다. `ESC @` · `ESC a` · `ESC !` · `LF` 네 가지만 해석하는 파서에 서비스용 영수증 생성 코드가 붙어 있었습니다. |
| **2026.10** | 범용 도구로 다시 정리했습니다. 서비스 전용 코드를 걷어내고, 어떤 ESC/POS 명령어든 붙여넣거나 블록으로 조립해서 확인할 수 있게 바꿨습니다. 파서가 해석하는 명령어를 늘렸고, 해석하지 못한 명령은 이유와 함께 알려줍니다. |

## 기능

### ✍️ 두 가지 입력 방식으로 작성해볼 수 있습니다

| 모드 | 설명 |
|---|---|
| **조립** | 텍스트 · 구분선 · 피드 · 바코드 · 커트 블록을 쌓아 영수증을 만듭니다. 텍스트 블록마다 정렬(좌/중/우)과 굵게 · 2배 · 밑줄 · 반전 토글이 있습니다. 맨 앞의 `ESC @` 초기화 블록은 고정입니다. |
| **직접 입력** | 명령어 원문을 그대로 넣습니다. `\x1B\x40` 형태의 이스케이프 문자열과 `1B 40 ...` hex 덤프를 모두 받습니다. hex는 텍스트 구간을 UTF-8 또는 EUC-KR(CP949)로 디코딩할 수 있습니다. |

두 모드는 하나의 내용을 공유합니다. 조립한 블록은 직접 입력으로 넘어가면 명령어가 되고, 직접 입력한 명령어는 조립으로 넘어가면 블록으로 돌아옵니다. 다만 한 줄 안에서 스타일이 바뀌거나, 폭만 2배이거나, CODE128이 아닌 바코드처럼 블록으로 담을 수 없는 요소는 가장 가까운 형태로 단순화되며 토스트로 안내합니다.

### 👀 세 가지 보기를 제공합니다

| 탭 | 설명 |
|---|---|
| **Preview** | 감열지 형태로 렌더링합니다. 용지 폭은 32 / 42 / 48 col 중 선택할 수 있고, 한글 2칸 · 영문 1칸으로 실제 프린터와 같은 위치에서 줄바꿈됩니다. |
| **Tokens** | 명령어는 칩으로, 텍스트는 글자 그대로 보여줍니다. 칩에 마우스를 올리면 오프셋과 원본 바이트를 확인할 수 있습니다. |
| **Issues** | 파서가 걸러낸 항목입니다. 알 수 없는 명령어, 유효하지 않은 인수, 바코드 길이를 22바이트로 선언해 놓고 8바이트만 넣은 경우 등을 기록합니다. |

**Copy hex** 버튼으로 현재 내용을 hex 덤프로 복사할 수 있습니다.

### 📋 지원하는 명령어

| 명령 | 동작 |
|---|---|
| `ESC @` | 초기화 |
| `ESC a n` | 정렬 — 0 좌, 1 중, 2 우 |
| `ESC ! n` | 인쇄 모드 비트 — 08 굵게, 10 2배 높이, 20 2배 폭, 80 밑줄 |
| `ESC E n` / `ESC - n` | 굵게 / 밑줄 |
| `ESC d n` / `ESC J n` | n줄 / n도트 피드 |
| `ESC i` / `ESC m` / `GS V m [n]` | 커트 |
| `GS B n` | 흑백 반전 |
| `GS ! n` | 글자 크기 |
| `GS h n` / `GS w n` / `GS H n` | 바코드 높이 / 모듈 폭 / HRI 위치 |
| `GS k m …` | 바코드 — NUL 종료형과 길이 지정형 모두 지원 |
| `ESC t` `ESC M` `ESC 2` `ESC 3` `ESC p` | 인식만 하며 화면에는 영향이 없습니다 |

같은 표를 앱 헤더의 **명령어** 버튼에서도 볼 수 있습니다. 바코드는 스캔 가능한 실제 심볼이 아니라 데이터로부터 모양만 만든 시각적 대역입니다.

## 🚀 실행

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # dist/
```

Vite 7 + TypeScript로 만들었고 런타임 의존성은 없습니다. 입력한 내용은 localStorage에 저장되어 새로고침해도 유지됩니다.

## 🗂 구조

| 경로 | 역할 |
|---|---|
| `src/main.ts` | UI, 상태, 모드 전환, 토스트 |
| `src/utils/escposParser.ts` | ESC/POS 문자열 → 노드 트리 + 토큰 + 진단, 렌더러 |
| `src/utils/decodeInput.ts` | 이스케이프 문자열 / hex → 바이트, 텍스트 인코딩 |
| `src/utils/blocks.ts` | 조립 블록 타입, 블록 ⇄ 명령어 변환, 데모 데이터 |
| `src/tokens.css` | 디자인 토큰 (OKLCH) |
| `src/style.css` | 레이아웃과 컴포넌트 |

파서는 바이트 배열이 아니라 문자열 위에서 동작합니다. 처음에는 `TextEncoder`로 바이트를 뽑았는데, `\xFF` 같은 제어 인수가 UTF-8 두 바이트로 늘어나면서 `GS B \xFF`가 깨지는 것을 보고 바꿨습니다. hex 입력은 latin1로 1:1 매핑해 파싱한 뒤 텍스트 구간만 선택한 인코딩으로 다시 디코딩합니다.
